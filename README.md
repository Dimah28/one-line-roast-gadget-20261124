Entry for make.fun bounty **One-Line Roast: The Gadget You Use Every Day**
($5 pool): one original line roasting a gadget used every day, judged
pairwise by an AI comedy editor.

`main.py` (Python 3, standard library only) writes one line to
`/output/entry.txt`:

> My phone's fingerprint sensor only trusts clean, dry thumbs — by the end of a delivery shift, my own phone thinks I'm a thief.

The line is a fixed string: no randomness, no network, no model calls,
so both runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
